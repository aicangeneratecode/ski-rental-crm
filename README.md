# Ski Rental CRM

Основа CRM лыжного проката на TailAdmin Free (MIT).

## Запуск

Node.js >= 20.9. В корне проекта:

```bash
npm ci
npm run dev
```

Открыть http://localhost:3000.

Проверки: `npm run lint`, `npm run build`.

## Текущее состояние

Русская оболочка, адаптивное меню, светлая/тёмная тема и пять страниц: Сегодня, Брони, Оборудование, Клиенты, Настройки. Это основа интерфейса: базы данных, авторизации и операций с клиентами пока нет. Не используйте для реальных персональных данных до подключения авторизации.

## Следующие этапы

1. PostgreSQL, каталог оборудования и тарифы RSD.
2. Клиенты, брони, расчёт оплачиваемых дней и проверка пересечений.
3. Выдача, возврат, оплаты, авторизация сотрудников.

Скидки и бесплатные позиции применяются только вручную. День на дорогу уменьшает оплату, но не период занятости оборудования. Подключаемые правила должны сохраняться в заказе.
